# Trabajos Prácticos Integradores - Programación I

Cada carpeta contiene un trabajo independiente. Ejecutar `python main.py` desde la carpeta correspondiente.

- TPI_1: listas paralelas y matrices (30 estudiantes).
- TPI_2: lista de diccionarios (1000 estudiantes de prueba).
- TPI_3: CSV y JSON. El archivo de ejemplo es `estudiantes.csv`.
- TPI_4: CSV, JSON, lambda, map y filter.

Los primeros 30 estudiantes de TPI_2, TPI_3 y TPI_4 coinciden con TPI_1.
